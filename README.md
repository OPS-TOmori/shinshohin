# 商品マスタ登録サイト（自社取扱商品カタログ）

ブランド（Az / Cocoa / グランフォト / ブライダル / アダマス）ごとにタブを切り替えながら、自社で取り扱っている商品（プロカラーさんの現行商品）を登録・一覧・編集できる社内向けサイトです。

- データの保存先: **Googleスプレッドシート**（見慣れた画面で中身を直接確認・修正できます）
- サーバー側の処理: **Google Apps Script**（Googleが無料でホストしてくれるので、Netlifyの「Functions」機能は使いません）
- 公開先: **Netlify**（今回は画像やHTML/CSS/JSだけを置く、ただの静的サイトとして公開します）

前のバージョン（Netlify Functions + Airtable）でNetlify側の関数デプロイがうまくいかなかったため、この構成に変更しました。Netlifyには純粋な静的ファイルしか置かないため、以前発生した「Failed to create function」のような問題自体が起こりません。

登録済みの商品にエルムさんの対応商品を当て込んでいく機能は、次のステップとして別途拡張する想定です（今回はまず自社商品の登録・カタログ化までです）。

---

## 0. 全体の流れ

1. Googleスプレッドシートを作る
2. Apps Script（Googleスプレッドシートに紐づく小さなプログラム）を貼り付けて「ウェブアプリ」として公開する
3. GitHubに `public` フォルダなど一式をアップロードする
4. Netlifyで静的サイトとして公開する
5. サイトを開き、初回だけApps ScriptのURLを入力する

所要時間の目安: 30分程度

---

## 1. Googleスプレッドシートの準備

1. https://sheets.google.com で新しいスプレッドシートを作成
2. シート下部のタブ名を **`商品マスタ`** に変更（このシート名を後でスクリプトが参照します）
3. 1行目（見出し行）に、以下をこの順番通りに入力してください（コピペ推奨）

```
ID	ブランド	商品名	品種	画像URL	色	ページ数	面数	プロカラー金額	年間受注数	年間原価	備考	登録日時
```

> これらの列は Apps Script が自動で読み書きします。2行目以降は空のままでOKです（サイトから登録すると自動で行が追加されます）。「年間原価」列には自動で数式が入ります。

---

## 2. Apps Scriptの設置

1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. デフォルトで開かれる `Code.gs`（中身は空、または `function myFunction() {}` のみ）の中身を**全部削除**
3. このフォルダの `google-apps-script/Code.gs` の中身を全部コピーして貼り付け
4. 左メニューの歯車アイコン「プロジェクトの設定」を開き、一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
   - プロパティ: `ACCESS_CODE`
   - 値: 社内で共有する任意の合言葉（例: `ono2026`）
   - ※ 設定しなければ合言葉なしで誰でも使えるサイトになります
5. 上部の「保存」（フロッピーディスクのアイコン）をクリック

### デプロイ（公開）する

1. 右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」の歯車アイコン→「ウェブアプリ」を選択
3. 設定:
   - 説明: 任意（例: `v1`）
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリック

### 初回の権限承認（重要）

初めてデプロイすると「承認が必要です」という画面が出ます。

1. 「アクセスを承認」をクリック
2. Googleアカウントを選択
3. 「このアプリはGoogleで確認されていません」という警告画面が出ますが、自分で作成したスクリプトなので問題ありません。「詳細」（左下あたりの小さいリンク）→「(プロジェクト名)に移動（安全ではないページ）」をクリック
4. 「許可」をクリックしてスプレッドシート・Google Driveへのアクセスを許可

完了すると、`https://script.google.com/macros/s/～/exec` という形のURLが表示されます。**このURLをメモしておいてください**（後でサイト側に設定します）。

### コードを修正した場合

`Code.gs` の内容を後から修正したときは、「デプロイ」→「デプロイを管理」→ 該当のデプロイの鉛筆アイコン →「バージョン」を「新しいバージョン」にして「デプロイ」し直してください。保存しただけでは公開中のウェブアプリには反映されません。

---

## 3. GitHubにアップロード

1. https://github.com で無料アカウントを作成（すでにお持ちならログイン）
2. 右上の「+」→「New repository」
3. Repository name に任意の名前（例: `shohin-touroku`）を入力し、「Create repository」
4. 作成後の画面にある「uploading an existing file」リンクをクリック
5. このフォルダの中身の **`public` フォルダの中身一式**（`index.html`, `app.js`, `styles.css`）と、ルートの `netlify.toml` をドラッグ&ドロップでアップロード

   ⚠️ GitHubの画面にドラッグするときは、フォルダそのものではなく中身を直接ドラッグしてください。リポジトリのトップに `netlify.toml` が直接見えている状態が正しい形です。

6. 「Commit changes」

---

## 4. Netlifyで公開

1. https://app.netlify.com にログイン
2. 「Add new site」（「Add new project」）→「Import an existing project」→「GitHub」→ 先ほどのリポジトリを選択
3. Publish directory が `public` になっていることを確認して「Deploy site」
4. 数十秒でURL（`https://xxxxx.netlify.app`）が発行されます

今回のサイトには関数(Functions)を一切使わないため、環境変数の設定は不要です。

---

## 5. サイトの初期設定・動作確認

1. 発行されたURLにアクセス
2. 「初期設定」画面が出るので、2章でメモしたApps ScriptのウェブアプリURL（`.../exec`）を入力し「保存して接続」
   - このURLはブラウザに保存されるため、次回からはこの画面は出ません
   - 別のパソコン・スマホからアクセスする場合は、それぞれの端末で最初の1回だけ入力が必要です
3. `ACCESS_CODE` を設定した場合は合言葉入力画面が出るので入力
4. ブランドタブを切り替えて「＋ 新規登録」から商品を1件登録してみる
5. Googleスプレッドシート側にも同じ内容の行が追加されていればOKです

画面右上の「接続設定」ボタンから、後でApps ScriptのURLを変更することもできます。

---

## セキュリティに関する注意事項

- 本サイトはプロカラーさんの単価情報など、社外に見せたくない情報を扱います。Netlifyが発行するURLも、Apps ScriptのURLも、知っている人なら誰でもアクセスできてしまうため、`ACCESS_CODE`（合言葉）は必ず設定することを推奨します。
- 合言葉方式は簡易的なものです（ブラウザの開発者ツール等で通信内容を見れば合言葉自体は分かってしまいます）。より厳密なアクセス制御が必要な場合は、Google Workspaceをお使いであれば「アクセスできるユーザー」を「自分のドメイン内の全員」に変更する、あるいは別途ログイン機能を追加することもご検討ください。
- 画像はGoogle Driveの専用フォルダ（`商品マスタ_画像`）に保存され、「リンクを知っている全員が閲覧可」の設定になります。フォルダ自体は作成者(あなた)のDrive内にあります。

## トラブルシューティング

- **「読み込みに失敗しました」と出る**: Apps ScriptのURLが正しいか、デプロイ時に「アクセスできるユーザー: 全員」になっているか確認してください。
- **合言葉が合っているのに入れない**: Apps Script側で `ACCESS_CODE` のスクリプトプロパティが正しく保存されているか、コードを修正した後に「新しいバージョン」でデプロイし直したか確認してください。
- **画像が表示されない**: Google Driveの共有設定が「リンクを知っている全員」になっているか確認してください（`saveImageToDrive` 関数が自動設定しますが、手動でDrive側の設定を変えてしまうと表示されなくなります）。
- **Code.gsを直しても反映されない**: 「デプロイを管理」から新しいバージョンとしてデプロイし直してください（2章末尾参照）。
